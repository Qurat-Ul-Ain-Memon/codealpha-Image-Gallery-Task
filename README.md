🌐 Web Dev Image Gallery
A modern and responsive Image Gallery Web Application developed using HTML, CSS, and JavaScript as part of the Code Alpha Internship Program. This project demonstrates front-end development skills with a focus on clean design, structured layout, and smooth user experience.

📖 Overview
This project is designed to showcase a visually appealing and well-organized image gallery. It follows best practices in file structuring and responsiveness, ensuring compatibility across different screen sizes and devices.

✨ Key Features
📱 Responsive Design – Optimized for mobile, tablet, and desktop
🖼️ Organized Image Layout – Clean and structured gallery view
⚡ Smooth User Interaction – Fast and user-friendly interface
🎨 Modern UI – Simple and elegant design
📂 Efficient File Management – Dedicated images folder
